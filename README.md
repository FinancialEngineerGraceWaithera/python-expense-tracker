# Python Expense Tracker

A beginner-friendly personal expense tracker built with Python.

## About the Project

This project is a command-line expense tracker that allows users to record their expenses, organize them by category, calculate total spending, and compare their spending against a monthly budget.

I built this project while learning Python fundamentals, with the goal of applying programming concepts to personal finance and financial analysis.

## Features

* Add multiple expenses
* Categorize expenses
* Enter expense amounts
* Continue adding expenses until finished
* Calculate total expenses
* Display an expense summary
* Calculate spending by category
* Handle categories consistently using lowercase input
* Set a monthly budget
* Calculate remaining budget
* Identify when spending exceeds the budget
* Calculate the percentage of the budget used
* Format financial figures for easier reading

## How to Run

Make sure Python is installed on your computer.

Clone or download this repository, then run:

```bash
python Building_Expense_tracker.py
```

The program will ask you to enter your expenses and monthly budget.
